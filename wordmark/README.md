# Yessir! wordmark

| File | Use on |
| --- | --- |
| `yessir-wordmark-light.svg` / `@1x` `@2x` `@4x.png` | light backgrounds (black text, blue `!` #2F5BD3) |
| `yessir-wordmark-dark.svg` / `@1x` `@2x` `@4x.png` | dark backgrounds (off-white #F6F6F4 text, light-blue `!` #7E9BE0) |

- Backgrounds are transparent. Each file includes 16px of clear space around the mark at 1x (383×93).
- The text is converted to outlines (JetBrains Mono ExtraBold), so the SVGs don't need the font installed.
- Prefer the SVG wherever possible. Use the PNGs for places that need images, like GitHub social previews and slides.
