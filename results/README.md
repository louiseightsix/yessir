# Results

One directory per experiment; inside it, one directory per run, named by configuration and seed.

**Rule:** everything here is either a result you would stand by, or is explicitly marked as flawed.

To mark a run as flawed, put a `README.md` in its directory whose first line is

```
FLAWED: <one-line reason>
```

followed by any detail (what is wrong, what it affects, whether a corrected run exists). Flawed runs stay so the history is honest; they are never cited without their annotation.

Prototype results are not here; they live with their prototype under `prototypes/` and carry no such guarantee.
