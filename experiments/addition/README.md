# Addition

**Can a transformer trained to do long addition in a few bases, each defined in the prompt, add in bases it never saw in training?**

See [`spec/task.md`](spec/task.md) for the task specification, [`reference.py`](reference.py) for the ground-truth column-addition oracle, [`inputs.py`](inputs.py) for shared tokens, sequence prefixes, and problem sampling, and [`evaluation.py`](evaluation.py) for shared evaluation metrics and the first-error taxonomy.
